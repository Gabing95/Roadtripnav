Come esportare le tue mappe

  1. Apri ogni mappa su Google My Maps (mymaps.google.com).
  2. Menu (☰) → Esporta al file KML/KMZ.
  3. Spunta "Esporta in formato KML anziché KMZ" — è importante, i file .kmz non sono supportati qui.
  4. Scarica il file per entrambe le mappe (se vuoi, anche livello per livello).
  5. Assicurati che ogni livello/cartella sia già nominato per giorno (es. "Giorno 1", "Giorno 2"...).

Carica qui sotto tutti i file .kml che hai esportato — puoi selezionarli insieme. Non preoccuparti se manca qualcosa: potrai aggiungere a mano photo spot, ristoranti o altre tappe anche più avanti, direttamente da qui.
